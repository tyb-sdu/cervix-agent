## 五、为什么现在不能直接强行压到 5,000–10,000

原方案给出了 P1-04 的筛选类别和预期数量，但没有给出在严格条件仍产生 93,180 条时应该采用的第二层规则、阈值、权重或并列处理。

如果智能体为了凑数量而临时收紧 MW/LogP、缩小 SMARTS、删除某类天然产物或自创综合评分，就会改变已锁定工作流，也无法保证科学合理性。

因此，当前正确状态是：

`P1-04 recorded scope complete = true`

但：

`5,000–10,000 secondary set not yet authorized`
