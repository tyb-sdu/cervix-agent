### 2.2 CYS51/CYS58 的四象限编号核对

| 原标签的解释方式 | 实际映射 | 是否为 Cys | 结论 |
|---|---|---:|---|
| `CYS51` 按 PDB author 编号 | F/H: Cys51 | 是 | 匹配 |
| `CYS51` 按 P03126 编号 | F/H: Asp44，对应 P03126 Asp51 | 否 | 不匹配 |
| `CYS58` 按 PDB author 编号 | F/H: Asn58，对应 P03126 Asn65 | 否 | 不匹配 |
| `CYS58` 按 P03126 编号 | F/H: Cys51，对应 P03126 Cys58 | 是 | 匹配 |

因此，原方案中的 “Cys51” 与 “Cys58” 可以在两套编号体系下指向同一个物理残基：

`4XR8 author Cys51 = P03126 canonical Cys58`

这不是两个已被结构确认的独立 Cys 位点。智能体不能自行把它们当成两个位点，也不能删除其中一个标签。

几何只读核验显示，该 Cys 的 SG 到同链最近 Zn 约 16.6–17.0 Å；它不是 4XR8 中典型的 Zn 配位 Cys。该距离只作为结构 QC，不等于已证明其反应性、可成药性或对接可行性。
